پروژه InstaTracker یک ابزار تحت‌وب کلاینت‌ساید (Client-Side) برای مقایسه و ردیابی تغییرات دنبال‌کنندگان (Followers) اینستاگرام در دو بازه زمانی مختلف است. این ابزار با مقایسه دو فایل خروجی دیتای اکانت، لیست دقیق افرادی که در این فاصله زمانی پیج را آنفالو کرده‌اند (Lost Followers) یا به جمع دنبال‌کنندگان اضافه شده‌اند (New Followers) را بدون نیاز به پسورد یا دسترسی به APIهای اینستاگرام استخراج می‌کند.

امکانات سایت

نسخه 1.0.5 نسخه فعلی

  • مقایسه دو بازه زمانی: دریافت دو فایل خروجی دیتای اینستاگرام (قدیمی و جدید) و تطبیق آن‌ها.

  • شناسایی افراد آنفالو کرده (Lost Followers): استخراج لیست دقیق کاربرانی که در فایل قبلی وجود داشته‌اند اما در فایل جدید حضور ندارند.

  • شناسایی فالوورهای جدید (New Followers): نمایش اکانت‌های جدیدی که به لیست دنبال‌کنندگان اضافه شده‌اند.

  • پردازش کاملاً محلی (حفظ امنیت و حریم خصوصی): پردازش ۱۰۰٪ دیتا در مرورگر کاربر (بدون ارسال داده‌ها به سرور یا ذخیره‌سازی).

  • بدون نیاز به اطلاعات ورود: بی‌نیاز از پسورد، لاگین یا اتصال به APIهای شخص ثالث اینستاگرام.

  • رابط کاربری ساده و واکنش‌گرا: طراحی ریسپانسیو و دسترسی سریع به لینک پروفایل کاربران در نتایج.

نحوه پردازش و منطق مقایسه

هسته اصلی این برنامه بر پایه مقایسه تفاوت مجموعه‌ها (Set Difference) در جاوااسکریپت عمل می‌کند:

  • خواندن و پارس کردن محتوای دو فایل بارگذاری‌شده از طریق FileReader API

  • تطبیق شناسه‌ها (Usernames) و استخراج ورودی‌ها و خروجی‌های هر بازه زمانی

  • بدون فشار به حافظه مرورگر و بهینه‌سازی شده برای لیست‌های با تعداد کاربر بالا

فناوری‌ها و ابزارها

  • HTML5

  • CSS3 : طراحی ریسپانسیو با Flexbox و Modern CSS

  • Vanilla JavaScript (ES6+) : منطق مقایسه آرایه‌ها و مدیریت DOM

  • FileReader API : پردازش محلی فایل‌ها

  • Git & GitHub Pages : کنترل نسخه و میزبانی

جمع‌بندی

پروژه InstaTracker ابزاری دقیق، سریع و متمرکز بر یک هدف مشخص است: ردیابی تغییرات فالوورها در دو بازه زمانی با تضمین امنیت کامل اطلاعات کاربر. این پروژه با معماری ماژولار پیاده‌سازی شده تا امکان اضافه کردن فیچرهای تحلیلی جدید در نسخه‌های بعدی به‌راحتی فراهم باشد.
