## 🎨 CSS Architecture

The stylesheet structure separates global foundations, layout, reusable components, animations, and page-specific styles.

- `base.css` — variables, resets, typography, and global foundations
- `layout.css` — shared page layout and structural styles
- `components.css` — reusable UI components
- `animation.css` — animations and transition utilities
- `home.css` — homepage-specific sections and styles
- `pages.css` — shared styles for inner pages
- `projects.css` — project-page-specific styles

This keeps shared styles reusable while avoiding unnecessary abstraction for sections that only exist on the homepage.
